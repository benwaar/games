Demo Steps

Step 1 — Load protected binary
Load protected.tap into the emulator. The binary contains a 26-byte XOR checksum verifier prefix followed by the payload.
Step 2 — Run (intact)
Execute the binary from load address 0x8000. The verifier computes the XOR checksum of the payload, compares against the embedded expected value — match → JP to payload → white stripe appears.
Step 3 — Tamper one byte
Flip one bit in the payload while the binary is loaded in RAM. The verifier hasn't run yet — tamper now before calling USR.
Step 4 — Run (tampered)
Execute again. The verifier recomputes the checksum — mismatch → JP to crash HALT. Payload never executes.
Load address0x8000
Verifier prefix0x8000 – 0x8019 (26 bytes)
Payload start0x801A
Tamper address0x801A (first payload byte)
Crash HALT0x8049

The verifier is 26 bytes of pure Z80: LD HL/BC, XOR loop over payload, CP against embedded constant, JP NZ to HALT.
Attacker bypasses: NOP out the JP NZ (3 bytes), or recompute the checksum constant after patching.
See incant/incant/protect.py for the full implementation.
