The module stores a payload in a data segment at offset 1024.
At startup $verify XOR-hashes the segment and compares to the embedded constant.
Match → returns 42. Mismatch → unreachable trap (WASM runtime exception).
See incant/incant/protect.py for generate_self_verify_wat.

Demo Steps

Step 1 — Run intact module
Instantiate protect.wasm and call run(). The verifier XOR-hashes the data segment — checksum matches → returns 42.
Step 2 — Tamper one byte
Flip the first bit of the payload in the raw WASM bytes before instantiation. The checksum will mismatch.
Step 3 — Run tampered module
Re-instantiate from the tampered bytes and call run(). The verifier detects mismatch → unreachable → runtime exception.
