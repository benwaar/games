Query the local knowledge corpus at `knowledge/chunks/` and return the most relevant chunk(s).

## Corpus layout

```
knowledge/chunks/
  z80-instruction/     — Z80 opcodes and instruction reference
  spectrum-rom/        — Spectrum ROM entry points, system variables, routines
  spectrum-hardware/   — ULA timing, hardware registers (not yet populated)
  wasm-spec/           — WASM binary format, WAT text format, runtime semantics
  wasi/                — WASI preview signatures and syscall reference
```

## Category aliases

| User prefix | Directory |
|---|---|
| `z80` | `z80-instruction/` |
| `rom`, `spectrum-rom` | `spectrum-rom/` |
| `hw`, `hardware`, `spectrum-hardware` | `spectrum-hardware/` |
| `wasm` | `wasm-spec/` |
| `wat` | `wasm-spec/` (filter for WAT-related chunks) |
| `wasi` | `wasi/` |
| _(no prefix)_ | all categories |

## Steps

1. **Parse the query from args.**
   - If the first word matches a category alias, strip it and set the search directory.
   - Everything else is the query string.
   - Examples:
     - `/z80 LD A, n` → query=`LD A, n`, dir=`z80-instruction/`
     - `/z80 rom CHAN-OPEN` → query=`CHAN-OPEN`, dir=`spectrum-rom/`
     - `/z80 wasm memory.grow` → query=`memory.grow`, dir=`wasm-spec/`
     - `/z80 wasi fd_write` → query=`fd_write`, dir=`wasi/`
     - `/z80 ULA timing` → query=`ULA timing`, dir=all

2. **Search filenames first.**
   Run: `ls knowledge/chunks/<dir>/`
   Find files whose stem matches any word in the query (case-insensitive). Score exact matches higher than partial.

3. **Grep chunk content.**
   Run: `grep -ril "<query>" knowledge/chunks/<dir>/`
   where `<query>` is the first significant term. For multi-word queries, grep for each word separately and intersect.
   Bash command to use (adapt dir and terms):
   ```bash
   grep -ril "CHAN-OPEN" knowledge/chunks/spectrum-rom/
   ```

4. **Read the best match(es).**
   Read the top 1–3 files. Prefer filename matches over content-only matches.

5. **Format the output.**
   For each result:
   - Print a header: `## <topic> (<category>)`
   - Print the frontmatter fields on one line: `source: <source_url> · licence: <licence>`
   - Print the chunk body (full content, no truncation unless >150 lines — then print first 100 and note how many lines remain)
   - If multiple results, separate with `---` and note `Showing N of M matches` at the top.

6. **No match handling.**
   If nothing is found: say so clearly and suggest a related category or a broader search term.

## Examples

```
/z80 LD A, n
/z80 rom CHAN-OPEN
/z80 wasm memory.grow
/z80 wasi fd_write
/z80 ULA timing
/z80 ADD HL
/z80 spectrum-hardware border
```
